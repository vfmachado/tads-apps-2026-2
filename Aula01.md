# Aula 1 — Introdução e configuração

## Objetivos

* Compreender o ecossistema React Native.
* Diferenciar React Native, Expo e desenvolvimento nativo.
* Executar o aplicativo em dispositivo físico ou emulador.

## Conteúdo

* React Native e sua relação com React.
* Expo Go, development builds e código nativo.
* Node.js, editor, dispositivo e emulador.
* Estrutura inicial do projeto.
* Metro Bundler e Fast Refresh.

## Prática

```
npx create-expo-app@latest meu-app
cd meu-app
npx expo start
```
