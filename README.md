

## Estrutura das aulas

| Aula | Tema                                         | Conteúdos principais                                                                                         | Atividade prática                                   |
| ---: | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- |
|    1 | Introdução ao desenvolvimento mobile         | Aplicações nativas, híbridas e multiplataforma; React Native; Expo; Android e iOS; organização do curso      | Criar, executar e modificar o primeiro projeto      |
|    2 | Fundamentos do React Native                  | JSX, componentes funcionais, propriedades, composição e diferenças entre React e React Native                | Criar componentes de cabeçalho, cartão e botão      |
|    3 | Estilização e layout                         | `StyleSheet`, Flexbox, espaçamento, dimensões, cores, tipografia e `SafeAreaView`                            | Construir a tela inicial do aplicativo              |
|    4 | Estado, eventos e renderização               | `useState`, eventos de toque, renderização condicional, atualização de estado e imutabilidade                | Criar contador e controle de conclusão de tarefas   |
|    5 | Listas e componentes reutilizáveis           | `FlatList`, `ScrollView`, `keyExtractor`, parâmetros, componentes de item e listas vazias                    | Exibir uma lista de tarefas ou registros            |
|    6 | Navegação entre telas                        | Expo Router, rotas baseadas em arquivos, Stack, Tabs, parâmetros e navegação programática                    | Criar telas de listagem, detalhes e configurações   |
|    7 | Formulários mobile                           | `TextInput`, teclado, tipos de entrada, componentes controlados e submissão                                  | Criar formulário de cadastro                        |
|    8 | Validação e experiência do usuário           | Regras de validação, mensagens de erro, feedback visual, acessibilidade e tratamento do teclado              | Validar o formulário de cadastro e edição           |
|    9 | Organização e arquitetura                    | Estrutura de pastas, separação entre telas, componentes, serviços, modelos, hooks e utilitários              | Refatorar o projeto para uma estrutura modular      |
|   10 | Consumo de APIs REST                         | HTTP, JSON, `fetch`, operações GET e POST, funções assíncronas e variáveis de ambiente                       | Carregar dados de uma API e cadastrar um registro   |
|   11 | Estados de comunicação e tratamento de erros | Loading, erro, sucesso, tela vazia, retry, timeout e atualização da interface                                | Implementar feedback completo durante requisições   |
|   12 | Persistência local                           | AsyncStorage, serialização, leitura, gravação e sincronização com o estado                                   | Salvar preferências e registros localmente          |
|   13 | Autenticação e estado global                 | Context API, providers, custom hooks, fluxo de login, logout e proteção de rotas                             | Criar autenticação simulada e rotas protegidas      |
|   14 | Recursos nativos, depuração e testes         | Câmera ou galeria, permissões, logs, React Native DevTools, testes de componentes e desempenho básico        | Adicionar imagem ao registro e testar um componente |
|   15 | Build, publicação e apresentação             | Configuração do aplicativo, ícone, splash screen, permissões, build Android/iOS e preparação para publicação | Gerar o build e apresentar o projeto final          |
